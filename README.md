# OverTheWire: Bandit (Levels 00 – 34)

### Progression & Key Concepts
* **Levels 00–05 (CLI Fundamentals):** Navigation, file inspection (`file`), wildcards, and handling special filenames (leading `-`, spaces).
* **Levels 05–10 (Searching & Filtering):** Advanced `find` constraints (size, permissions), text processing (`grep`, `sort`, `uniq`, `strings`), and I/O redirection/piping (`|`).
* **Levels 10–15 (Data Manipulation & Networking):** Base64/ROT13 decoding, archivers (`tar`, `gzip`, `bzip2`), hex dumps (`xxd`), SSH keys, and raw socket connectivity (`nc`, `openssl`).
* **Levels 15–20 (Services & Privilege Escalation):** Port scanning (`nmap`), encrypted SSL/TLS channels, file diffing (`diff`), and foundational SETUID binary behavior.
* **Levels 20–25 (Automation & Task Scheduling):** Local netcat listeners, background process control (`&`), cron job analysis (`/etc/cron.d`), and shell scripting for brute-forcing.
* **Levels 25–30 (Git & Shell Breakouts):** Escaping restricted login shells via pager/editor triggers (`more` + `vim`), Git history traversal (`git log`, `git show`), and remote branch inspection (`git branch -a`).

### Core Toolset
`ssh` | `nc` | `openssl` | `nmap` | `git` | `find` | `grep` | `xxd` | `vim`
